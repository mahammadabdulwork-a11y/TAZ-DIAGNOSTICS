# TAZ COMPANY — TAZ DIAGNOSTIC

TAZ COMPANY is the project workspace for the TAZ DIAGNOSTIC Laboratory Management System.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL (next phase)
- UI theme: Premium Maroon Medical

## Start

### 1. Frontend
```powershell
cd client
npm install
npm run dev
```

### 2. Backend
Open another terminal:
```powershell
cd server
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5000
